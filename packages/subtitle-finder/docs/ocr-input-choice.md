# 喂 OCR：关键帧（原始帧） vs 去背景字幕图（ISA/mask）

> 实验结论：**在这个测试视频上，喂「关键帧原始帧」比喂「去背景 ISA/mask」识别更准**。
> 去背景二值化会丢失文字笔画，导致 OCR 误判/丢字。

## 实验（用 subtitle-ocr 对同一字幕段的三种图 OCR）

| 段（时间） | C++ RGB（原始帧） | C++ ISA（去背景） | Rust 原帧 | Rust mask（去背景） |
|---|---|---|---|---|
| 段0 (133-932) | **弱者** | 空（丢） | **弱者** | 空（丢） |
| 段1 (933-2265) | **这小子也真是敢说** | 这小子也真量敢说（错） | **这小子也真是敢说** | 这小子也真量敢说（错） |
| 段2 (2266-3499) | **这可是剑仙啊** | 这可是剑仙响（错） | **这可是剑仙啊** | 这可是剑仙啊 |
| 段3 (3700-5032) | **不行我得出手了** | 不行我得出手了 | **不行我得出手了** | 不行我得出手了 |

- 真实字幕以 C++ RGB + Rust 原帧（两个独立管线一致）为准：段1="这小子也真是敢说"、段2="这可是剑仙啊"。
- **C++ ISA 与 Rust mask（去背景图）都丢笔画**：段0 丢字、段1"量"（应为"真"）、段2"响"（应为"啊"）。

## 结论

- **不要**把去背景 ISA/mask 直接喂 OCR —— 当前二值化会丢笔画，识别反而不如原始帧。
- **应该**喂**关键帧原始帧**（配合 subtitle-ocr 的 `--subtitle-only` bottom_only ROI）。
- VideoSubFinder 官方推荐 ISA 的前提是**高质量去背景 + 字符增强**（笔画保持）。
  当前 Rust mask / C++ cli ISA 都没做字符增强，笔画丢失，故用原始帧更稳。
- 若后续要实现"去背景喂 OCR"，需要先补齐字符增强（保持笔画），否则会退化。

## 建议架构

```
subtitle-finder（关键帧 + 时间轴）
    │
    ├─ 原始关键帧 BGR ──► subtitle-ocr（bottom_only ROI）──► 文本   ← 当前推荐
    │
    └─（未来）增强版去背景 ISA ──► subtitle-ocr ──► 文本   （需先做字符增强）
```

当前 `subtitle-finder` 输出 `Keyframe{ frame: 原始BGR, mask: ISA }` 两者都有，
下游 `subtitle-ocr` 用 `frame`（原始帧）即可。
